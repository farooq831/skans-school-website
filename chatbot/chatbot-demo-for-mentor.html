SKANS Help Chatbot

A button-based help chat for the main website and all 9 campus websites. Parents pick a campus and a topic, and the chat opens the right page of that campus, answers common questions, or connects them to the campus on WhatsApp. No AI, no running cost, nothing that can give a wrong answer.

Close the chat (×) to see the waving SKANS button. Links open the real campus pages.
https://skansschool.edu.pk/

How it works

On the main site

The chat greets the parent and asks which campus they are interested in. After a campus is chosen, every button opens that campus’s own page. The choice is remembered on the parent’s device.

On a campus site

The chat recognises the campus from the web address and goes straight to its topics. A parent can still switch to another campus.

Typed questions

The search box matches keywords (for example “fees”, “documents”, “fsc”, “Westridge Senior fees”). If nothing matches, it says so honestly and offers WhatsApp and a call to the campus.

Always a human next

Every answer ends with WhatsApp and Call buttons for the chosen campus, so a parent is never stuck.

Install and maintenance

Files

One folder on the main site, public_html/chatbot/:

  • chatbot.js and chatbot.css: the chat window
  • campuses.js: names, addresses, phones, WhatsApp
  • faq.js: the common questions

Add to a website

One line before </body>:

<script src="https://skansschool.edu.pk/chatbot/chatbot.js?v=1" defer></script>

Main site: index.html. Campus sites: includes/footer.php.

Change an answer or number

Edit faq.js or campuses.js in cPanel File Manager and save. All 10 websites update at once. A typing mistake only hides the chat button; it never breaks a page.

Cost and data

  • No AI service, no API key, no monthly cost
  • No server code or database
  • Collects no personal data
  • Works on phone, tablet and computer
