SKANS AECHS CAMPUS - NEW WEBSITE, GO-LIVE PACKAGE (version 2.0.0, 7 Oct 2026)
==============================================================================

WHAT IS IN THIS FOLDER
  1-website\                     The new website: ONLY the files the server needs (234 files, 22 MB).
  skans-website-v2.0.0-....zip   The same 1-website folder as a zip, ready to upload.
  2-database\                    SQL to run in phpMyAdmin, numbered in order.
  3-server-config\campus-data\   2 small files you fill in ON THE SERVER (passwords). Never zip or share them.
  Full guide with every click: docs\deploy.md (in the project).

NOT IN THE PACKAGE (on purpose)
  - Pictures (adminpanel\upload\images) and student photos (uploads\): already on the live server; copy them across.
  - _old\, docs\, backups\, test files, and any password.

------------------------------------------------------------------------------
STEPS
------------------------------------------------------------------------------
 1. BACKUP the live site:
      cPanel > File Manager > current site folder > Compress > download.
      cPanel > phpMyAdmin > live database > Export > Quick > SQL > Go > save.

 2. cPanel > Domains: create a test subdomain (e.g. new-aechs.skansschool.edu.pk)
    with its own folder (e.g. public_html/new-aechs). Select PHP Version: 8.1 or 8.2. Run AutoSSL.

 3. Upload the zip into that folder > Extract > delete the zip.
    Copy from the OLD site folder into the NEW one:
      adminpanel/upload/images/   (all pictures)
      uploads/                    (student photos)

 4. In the new folder, campus-data/ already exists (with its .htaccess). Add:
      campus-data/sites.php           from 3-server-config  (put the real web addresses)
      campus-data/aechs/config.php    from 3-server-config  (database name/user/password, email password)
    Test: open https://<test address>/campus-data/aechs/config.php  -> must say 403 Forbidden.

 5. DATABASE: phpMyAdmin > live database > SQL tab > paste each file > Go:
      01-check-before.sql              look only; screenshot the row counts
      02-schema.sql                    REQUIRED  (adds 2 tables + 1 column, deletes nothing)
      03-settings.sql                  recommended (campus details, phones, social links, post limit)
      04-optional-remove-old-news.sql  only with sir's approval (keeps a copy)
      05-optional-fix-encoded-text.sql optional, run twice
      06-check-after.sql               look only; row counts must match step 01
      08-academic-levels.sql           recommended: level cards = Academic Programs #1-#3 (keeps a copy)
    Error "#1060 Duplicate column name 'created_at'" in 02 = already there, that's fine.

 6. TEST everything on the test address (checklist in docs\deploy.md, step 6). Get sir's OK.

 7. GO LIVE: export the database once more, then cPanel > Domains > main AECHS domain >
    change its folder to the new one. Make sure campus-data/sites.php lists the main address.

 8. UNDO if needed: point the domain back to the old folder (1 minute).
    Database: the old site works with it as it is. 99-undo.sql only if you want it exactly as before.

 9. AFTER: cPanel > Cron Jobs > once per day:
      /usr/local/bin/php /home/CPANELUSER/public_html/new-aechs/adminpanel/cron_backup.php --campus=aechs
    Then check the fees once: Admin > Settings > Fee structure (session 2026-2027).

 07-useful-queries.sql: unlock a locked admin, unanswered messages, monthly post count, reset fees/principal.
